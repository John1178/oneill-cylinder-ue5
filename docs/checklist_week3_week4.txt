===============================================================================
 THINGS THAT WILL BITE YOU  (learned the hard way)
===============================================================================

 * PCG graphs: edit in the EDITOR, not through Python.
   Python writes while the editor is open corrupted the graph
   ("Invalid PCGGraph", nodes silently refuse to place).

 * After renaming/moving assets: SAVE THE LEVEL, then delete redirectors.
   Doing it the other way round nulled 58 mesh references.

 * Mesh Sampler default radius is 10 uu = 10 cm.
   At 13 km scale that will hang the editor. Use 5000.

 * A default cube is 100 uu. At station scale it is invisible.
   Scale points up (~50x) or you will think nothing spawned.

 * Load Data Table has no input pin - right-click empty space to add it.
